# Contributing

These tools are open source so that anyone can use, read and adapt them. The
repository is not organised around outside contributions.

## Issues

An issue is the channel we can act on: a bug, a tool that gets a project
wrong, or something a tool should handle and does not. Name the tool and the
version or commit, and what you ran it against if you can share it.

## Pull requests

We generally do not merge them. Reviewing an outside change costs us more time
than making the change ourselves. Open one anyway and we will read it; the
likely outcome is an issue that records your point, with the change made
separately.
